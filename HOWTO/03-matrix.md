# `mez matrix` — reachable, unwired, or genuinely missing

```
mez matrix                       against $MEZ_ESTATE
mez matrix --estate /path
```

Three states, and the middle one is the point:

| | |
|---|---|
| ✓ **wired** | present and the desk can reach it |
| ? **elsewhere** | it exists in the estate and the desk **cannot** reach it |
| × **gap** | nothing in the estate does this |

The test for completeness is not *"do we have a repository called Factory Automation?"* It is
*"can the same substrate represent, teach, simulate, perform, verify, preserve and retrieve factory
automation?"* If yes, it is covered architecturally even where a particular application is not yet
built.

## Why the grid is two axes and not six

The stated axes are activity × modality × lifecycle stage × actor scale × domain × environment.
Enumerated in full that is hundreds of thousands of cells, and filling them would produce a wall of
ticks nobody wrote and nobody can check — a fabrication machine wearing a spreadsheet. So the grid
is **activity × modality**; the other four are recorded per cell as qualifiers, and probes cut
across all six.

## The five probes

Deliberately unalike, so that passing all five tests the universal claim rather than asserting it:

- **litigation simulation** — symbolic, institutional, adversarial, evidence-heavy
- **factory automation** — physical, deterministic, cyberphysical, real-time
- **courses** — developmental, pedagogical, human-centred
- **research** — epistemic, exploratory, verification-heavy
- **art and media** — generative, expressive, multimodal

A probe passes only when every cell it needs is **wired**. Never on *elsewhere* — owning a
capability and being able to use it are different things, and confusing them is the confusion this
whole exercise exists to end.

## The recurring defect

Four capabilities were once marked "not built" that already existed and ran. That was a **wiring
gap**, not a missing build. Before adding a repository, check this matrix: the answer is more often
a call than a component.
