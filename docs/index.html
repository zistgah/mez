A desk you own, that runs with the network unplugged.

This page is the shop window. The desk itself is a folder on your machine — nothing here uploads anything, and nothing here pretends to be running when it is not.

Seven seats

Who is sitting down?

Your seat changes what is shown — never what is computed. Everyone gets the same numbers; you get the panels that matter to you.

The bench

Everything is a drop-in.

Each of these keeps its own repository, its own studio and its own contract. The desk mounts them; it reimplements none of them. Where a studio is a static page, it opens straight from here with nothing installed.

The lamp above is a live probe of 127.0.0.1:7373. If your desk is running, tools it can reach light up. If it is not, this page says so rather than guessing — that is the same rule the desk keeps: never pretend, and no stub that looks alive.

Three rungs

Same numbers, three ways to sit.

Console

The CLI. Everything arrives here first, works over ssh, needs no display.

Studio

An IDE-shaped surface: tools on the rail, the component's own page in the middle, the estate's state on the right.

Dome

The immersive rung, mounted from the shared dome — one library, one world config, never a fork.

The rung changes what is shown, never what is computed. A console user and a dome user get the same answer to the same question.

Sit down

Two lines.

$ git clone https://github.com/zistgah/mez && cd mez
$ python3 bin/mez_studio.py serve   # http://127.0.0.1:7373
$ ./mez bearings     # where you are, in ten seconds
$ ./mez doctor       # built · wired-but-unproven · honestly not built
$ ./mez studio       # what is mounted, what is reachable
$ ./mez badges       # the estate, scored against ACM / NISO / FAIR4RS

Pure Python standard library. No pip, no account, no key. $MEZ_HOME holds plain CSV and JSON, and the export format is the storage format. Cells you set by hand are never overwritten by an import.
