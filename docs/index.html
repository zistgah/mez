A desk you own, that runs with the network unplugged.

This page is the published face of it. Everything it can reach lives in its own repository with its own contract — this is a place to stand, not another application.

Take a seat

Your role changes what is shown. Never what is computed.

Seven seats at the same table, reading the same numbers. Pick one and the bench below reorders around what you actually do; nothing is hidden that you could otherwise reach, and nothing is calculated differently.

The bench

What is laid out.

Each tool keeps its own repository, its own studio and its own contract. Start the desk on your own machine and the lamp lights: every tool then reports whether it is answering, sitting on disk unstarted, or not here at all.

Start the desk

Two lines, and the lamp comes on.

$ git clone https://github.com/zistgah/mez && cd mez
$ python3 bin/mez_studio.py serve   # http://127.0.0.1:7373

Then reload this page. It probes 127.0.0.1:7373 from your own browser — nothing is sent anywhere, and if the desk is silent this page says so rather than guessing.

Where your things live
$MEZ_HOME, default ~/.mez. Plain CSV and JSON — the export format is the storage format, and a cell you set by hand is never overwritten by an import.
Three rungs
The console over ssh with no display; this 2D surface; and the immersive rung mounted into the dome. The same numbers on all three.
Never pretend
A stub that looks alive is worse than an honest gap. Anything absent says so, says where it looked, and gives you the line to type.
No vendor
Components are data in components.json. Delete every one and the desk still runs.
